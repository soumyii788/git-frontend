# Frontend Web Development - Week 2 Assignments

A collection of foundational HTML5 and CSS3 practice modules created by Soumya Shukla.

## Modules Included

1. **About Me Page (`Htmlindex.html`)**
   - Personal introduction card.
   - Showcases CSS pseudo-elements (`::first-line`), attribute selectors, and badges.

2. **CSS Positioning Guide (`CSSPosition.html`)**
   - Visual demonstration comparing `static` vs `relative` positioning in the CSS box model.

3. **Favorite Cities List (`city.html`)**
   - Ordered list with Roman numerals, CSS gradients, hover animations, and card shadows.

4. **Favorite Movies List (`Html_1.html`)**
   - Unordered list with custom square bullets and ID-based highlight badges.

## Technologies Used
- HTML5
- CSS3
