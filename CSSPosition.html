CSS Position Property

Understanding Static vs Relative Positioning

What is CSS Positioning?

The CSS position property sets how an element is positioned in the document. It can be static, relative, absolute, fixed, or sticky. Below, we demonstrate the differences between static and relative positioning.

Static

Static Positioning (Default)

Elements with position: static are not affected by top, bottom, left, or right properties. They flow naturally in the document.

I am a static box

position: static
Relative

Relative Positioning

Elements with position: relative are positioned relative to their normal position. The offset is applied but the element still occupies its normal space.

I am a relative box

position: relative;
top: 20px; left: 30px;

Key Differences

Static

  • ✓ Default positioning
  • ✓ Follows document flow
  • ✗ No offset properties
  • ✓ Simplest layout

Relative

  • ✓ Positioned relative to normal
  • ✓ Accepts offset properties
  • ✓ Still takes up space
  • ✓ Useful for fine-tuning
